# Telegram Style Vue Chat

Простой Telegram-style чат, созданный на Vue.js.

Проект реализует авторизацию, список чатов, отправку сообщений, изображений, файлов и запись голосовых сообщений через микрофон.

## 🚀 Demo

Проект находится в разработке.

## 🛠 Technologies

- Vue.js 3
- JavaScript
- HTML5
- CSS3
- Vite
- Lucide Vue Next
- MediaRecorder API
